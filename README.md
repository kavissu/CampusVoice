# Campus Voice

**University Complaint and Resource Management System**

## About the Project

Campus Voice is a university-based system designed to simplify complaint handling and resource management. It allows users to report equipment faults and general complaints, while helping university staff manage, assign and track reported issues.

## Main Features

- Equipment fault reporting through QR codes.
- General complaint submission without login.
- Unique complaint tracking codes.
- Automatic complaint assignment.
- Staff and equipment management.
- Ticket status tracking.
- Administrative dashboard and reports.

## Technology Stack

- **Mobile:** Flutter
- **Web:** React
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **ORM:** SQLAlchemy
- **Version Control:** Git and GitHub
